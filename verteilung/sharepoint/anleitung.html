2. Installieren (einmal je PC, ca. 2 Minuten)

  1. In SharePoint diesen Ordner öffnen und oben auf „Herunterladen“ klicken. Die ZIP-Datei im Ordner Downloads mit Rechtsklick → „Alle extrahieren …“ entpacken.
    Alternativ: Ordner mit „Synchronisieren“ bzw. „Verknüpfung zu „Meine Dateien“ hinzufügen“ auf den PC holen.
  2. Im entpackten Ordner auf Installieren.cmd doppelklicken.
  3. Falls Windows „Der Computer wurde durch Windows geschützt“ meldet: auf Weitere Informationen → Trotzdem ausführen klicken. (Das Programm ist nicht kostenpflichtig signiert; die Warnung erscheint nur einmal.)
  4. Ein schwarzes Fenster zeigt den Fortschritt. Danach startet die Buchhaltung als eigenes Fenster, und auf dem Desktop sowie im Startmenü gibt es die Verknüpfung „Omikron Buchhaltung“.
Keine Administratorrechte nötig. Das Programm wird nur für den angemeldeten Windows-Benutzer installiert (%LOCALAPPDATA%\Programs\Omikron-Buchhaltung).

3. Erster Start

  1. Einstellungen → Firmendaten: Anschrift, Steuernummer bzw. USt-IdNr. und Bankverbindung eintragen – diese Angaben stehen auf jeder Rechnung.
  2. Einstellungen → Rechnung & Steuer: Besteuerung und MwSt.-Satz prüfen.
  3. Arbeitskalender → Einstellungen: Stundensatz, Kilometersatz und Anfahrtspauschale eintragen.
  4. Optional: Einstellungen → Anmeldung & Benutzer – Passwortschutz einschalten.

Das Programm läuft im Hintergrund weiter (Symbol mit den drei Waben unten rechts neben der Uhr, ggf. unter dem Pfeil ^). Klick darauf öffnet das Fenster, Rechtsklick → Beenden schließt das Programm ganz.

4. Updates – kommen automatisch

  • Das Programm prüft beim Start und alle 6 Stunden, ob es eine neue Version gibt.
  • Gibt es eine, wird sie beim nächsten Start automatisch installiert – vorher legt das Programm eine Sicherung an. Oder sofort über den Hinweis „Jetzt aktualisieren“ in der Oberfläche.
  • Jede Datei wird beim Herunterladen mit einer Prüfsumme kontrolliert. Ihre Daten bleiben bei jedem Update erhalten.
  • Was neu ist: Klick auf die Versionsnummer unten links im Programm.
Den Ordner in SharePoint müssen Sie für Updates nicht erneuern. Er wird nur für neue PCs gebraucht – und auch dann lädt Installieren.cmd immer die neueste Version.

5. Ihre Daten und die Datensicherung

  • Die Daten (Datenbank, Rechnungs-PDFs, Belege, Fotos) liegen auf diesem PC in %LOCALAPPDATA%\Omikron-Buchhaltung\Daten. Öffnen: Rechtsklick auf das Symbol neben der Uhr → Daten-Ordner öffnen.
  • Das Programm erstellt täglich selbst eine Sicherung. Empfehlung: unter Einstellungen → Backup → Zusätzlicher Backup-Ordner einen mit OneDrive/SharePoint synchronisierten Ordner eintragen (z. B. eine Dokumentbibliothek „Sicherungen Buchhaltung“). So liegt immer eine Kopie im Microsoft 365.
  • Wiederherstellen: Einstellungen → Backup → Sicherung wiederherstellen (ZIP auswählen oder hochladen).
Wichtig bei mehreren Arbeitsplätzen: Jeder PC hat seinen eigenen Datenbestand. Soll das ganze Team mit denselben Daten arbeiten, ist die Browser-Version (Betrieb in Microsoft Azure, Anmeldung mit dem Microsoft-Konto, Aufruf direkt aus SharePoint) die richtige Lösung – bitte dafür bei uns melden. Das Programm bitte nicht direkt aus dem SharePoint-/OneDrive-Ordner starten und den Datenordner nicht in OneDrive legen: Die Synchronisierung kann eine geöffnete Datenbank beschädigen.

6. Umzug auf einen neuen PC

  1. Alter PC: Einstellungen → Backup → Backup jetzt erstellen und die neueste ZIP-Datei in der Liste darunter herunterladen.
  2. Neuer PC: wie in Abschnitt 2 installieren.
  3. Einstellungen → Backup → Sicherung wiederherstellen und die ZIP-Datei hochladen.

7. Entfernen

Deinstallieren.cmd doppelklicken. Programm und Verknüpfungen werden entfernt, die Daten bleiben erhalten (bei einer erneuten Installation sind sie sofort wieder da). Nur wer im Fenster ausdrücklich LOESCHEN eintippt, löscht auch die Daten.
