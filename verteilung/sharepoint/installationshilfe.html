Installation unter Windows

Omikron Buchhaltung · Schritt für Schritt und Hilfe bei Problemen

Zuerst prüfen: Arbeiten Sie an einem Mac (Apple)?
Die Datei Omikron-Buchhaltung.exe ist ein Windows-Programm und lässt sich auf einem Mac, iPad oder iPhone grundsätzlich nicht öffnen. Für Apple-Geräte gibt es die Browser-Version (läuft in Safari, Chrome oder Edge, ohne Installation) – bitte melden Sie sich dafür kurz bei uns.

1. Programm speichern

  1. Legen Sie einen eigenen Ordner an, z. B. C:\Omikron-Buchhaltung (Explorer öffnen → Dieser PC → Lokaler Datenträger (C:) → Rechtsklick → Neu → Ordner).
    Bitte nicht unter „Programme“, nicht in OneDrive/SharePoint und nicht auf dem Desktop eines OneDrive-Kontos – das Programm muss dort seine Updates speichern dürfen.
  2. Kam die Datei per E-Mail: Anhang mit Rechtsklick → Speichern unter … in diesen Ordner speichern. Nicht direkt aus der E-Mail-Vorschau starten.
  3. Kam eine ZIP-Datei: Rechtsklick → Alle extrahieren … → Zielordner wählen. Aus der ZIP-Datei heraus startet das Programm nicht.

2. Freigeben (einmalig)

Windows markiert Dateien aus dem Internet oder aus E-Mails. Damit es beim Start keine Probleme gibt:

  1. Rechtsklick auf Omikron-Buchhaltung.exe → Eigenschaften.
  2. Unten bei Sicherheit den Haken „Zulassen“ setzen (falls vorhanden) → OK.

3. Starten

  1. Doppelklick auf Omikron-Buchhaltung.exe.
  2. Erscheint die blaue Meldung „Der Computer wurde durch Windows geschützt“:
    Der Computer wurde durch Windows geschützt Weitere Informationen
    Von Microsoft Defender SmartScreen wurde der Start einer unbekannten App verhindert …
    App: Omikron-Buchhaltung.exe · Herausgeber: Unbekannter Herausgeber
    Trotzdem ausführenNicht ausführen
    zuerst auf „Weitere Informationen“ klicken → dann erscheint der Knopf „Trotzdem ausführen“ → anklicken.
    Diese Warnung erscheint, weil das Programm nicht mit einem kostenpflichtigen Zertifikat signiert ist. Sie kommt nur beim ersten Start.
  3. Bitte bis zu 30 Sekunden warten. Beim ersten Start entpackt sich das Programm – in dieser Zeit ist nichts zu sehen. Bitte nicht mehrfach doppelklicken.
  4. Die Buchhaltung öffnet sich als eigenes Fenster. Unten rechts neben der Uhr (ggf. unter dem Pfeil ^) erscheint das Symbol mit den drei Waben – darüber öffnen und beenden Sie das Programm.
  5. Tipp: Rechtsklick auf die EXE → Weitere Optionen anzeigen → Senden an → Desktop (Verknüpfung erstellen).

4. Es klappt nicht? – Hilfe nach Fehlerbild

Was passiertLösung
Datei lässt sich nicht öffnen / Windows fragt „Wie möchten Sie diese Datei öffnen?“ Sie arbeiten vermutlich an einem Mac oder die Datei hat keine Endung .exe mehr (manche E-Mail-Programme benennen sie um). Am Mac: Browser-Version nutzen (siehe oben). Unter Windows: Datei neu anfordern bzw. aus dem SharePoint-Ordner nehmen.
E-Mail-Anhang fehlt oder ist gesperrt („potenziell unsichere Anlage blockiert“) Outlook und viele Firmen-Postfächer sperren .exe-Dateien. Bitte die Datei stattdessen aus dem SharePoint-Ordner oder über den Download-Link holen, den Sie von uns erhalten.
Blaue Meldung „Der Computer wurde durch Windows geschützt“, nur Knopf „Nicht ausführen“ Auf den kleinen Text „Weitere Informationen“ klicken – erst dann erscheint „Trotzdem ausführen“.
„Smart App Control hat eine App blockiert …“ (ohne Knopf zum Ausführen) Windows 11 mit eingeschalteter intelligenter App-Steuerung lässt nur signierte Programme zu. Prüfen: Start → Windows-Sicherheit → App- & Browsersteuerung → Einstellungen für intelligente App-Steuerung. Steht sie auf „Ein“, bitte nicht selbst ausschalten, sondern bei uns melden – wir stellen Ihnen dann die Browser-Version bzw. eine signierte Fassung bereit.
„Diese App wurde von Ihrem Systemadministrator blockiert“ bzw. „Ihre Organisation hat … blockiert“ Firmen-PCs mit zentraler Verwaltung (z. B. Microsoft Intune) erlauben keine eigenen Programme. Ihre IT muss Omikron-Buchhaltung.exe freigeben – oder Sie nutzen die Browser-Version.
Datei ist plötzlich verschwunden oder „Virus oder potenziell unerwünschte Software erkannt“ Der Virenschutz hat die Datei vorsorglich in Quarantäne verschoben. Windows-Sicherheit → Viren- & Bedrohungsschutz → Schutzverlauf → Eintrag öffnen → Aktionen → Zulassen. Bei anderen Virenschutz-Programmen (z. B. Avast, ESET, Norton) dort eine Ausnahme für die Datei bzw. den Ordner anlegen. Danach die Datei erneut speichern.
Doppelklick – es passiert nichts 30 Sekunden warten und unten rechts neben der Uhr (Pfeil ^) nach dem Waben-Symbol schauen – ein Klick darauf öffnet das Fenster. Läuft das Programm schon, öffnet ein weiterer Doppelklick nur das Fenster erneut. Sonst: Schritt 2 (Freigeben) prüfen und den PC einmal neu starten.
„Windows kann nicht auf das angegebene Gerät, den Pfad oder die Datei zugreifen“ Die Datei liegt noch in der ZIP-Datei, in der E-Mail oder in einem gesperrten Ordner. Wie in Schritt 1 in einen eigenen Ordner auf C:\ speichern bzw. entpacken.
Fenster öffnet sich, bleibt aber leer oder „Seite nicht erreichbar“ Einige Sekunden warten und mit F5 neu laden. Hilft das nicht: Programm über das Waben-Symbol → Beenden schließen und neu starten.
Immer noch Probleme? Schicken Sie uns ein Foto oder einen Screenshot der Meldung (Windows + Umschalt + S) und ob Sie Windows 10 oder 11 nutzen (Start → Einstellungen → System → Info).
